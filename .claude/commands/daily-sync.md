# /daily-sync

Run the morning briefing for this workspace:

1. Read `data/daily-logs/` for the most recent entry (yesterday's or last session's) for continuity.
2. Check status of any active project(s) under `data/projects/` and run `git status` in the relevant repo(s) if applicable.
3. Review `data/inbox/` for untriaged items.
4. Summarize: what's in flight, what's blocked, what the sensible next actions are.
5. Append a new entry to `data/daily-logs/<today's date>.md` with that summary.
